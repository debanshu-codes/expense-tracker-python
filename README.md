# 💰 Personal Expense Tracker

A simple command-line Personal Expense Tracker built with Python. This project allows users to record, view, and calculate their expenses while storing the data locally in a JSON file.

## ✨ Features

* ➕ Add a new expense
* 🏷️ Enter an expense category
* 💰 Record the amount spent
* 📝 Add a short description
* 📋 View all saved expenses
* 🧮 Calculate total money spent
* 💾 Store expense data using JSON
* 🚪 Exit the application through a simple menu

## 🛠️ Technologies Used

* **Python 3**
* **JSON**
* **Lists and Dictionaries**
* **Loops and Conditional Statements**
* **File Handling**
* **Git & GitHub**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/debanshu-codes/expense-tracker-python.git
```

### 2. Navigate to the project folder

```bash
cd expense-tracker-python
```

### 3. Run the program

```bash
python tracker.py
```

## 🎮 How It Works

When the program starts, the user is presented with a menu:

```text
--- PERSONAL EXPENSE TRACKER ---

1. Add Expense
2. View All Expenses
3. View Total Spent
4. Exit
```

### Add Expense

The user enters:

* Expense category
* Amount
* Short description

The information is stored locally in JSON format.

### View All Expenses

Displays all previously recorded expenses along with their category, amount, and description.

### View Total Spent

Calculates and displays the total amount spent across all recorded expenses.
